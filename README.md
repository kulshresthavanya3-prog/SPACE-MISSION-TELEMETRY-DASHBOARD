# 🚀 Space Mission Telemetry Dashboard | Power BI Project

## 📌 Project Overview
An interactive dashboard built with Microsoft Power BI to visualize and monitor real-time telemetry analytics of major Indian space missions including **Aditya-L1, Chandrayaan-3, AstroSat, Mars Orbiter Mission, and XPoSat**.  
The dashboard simulates a mission-control system by providing insights into spacecraft performance, engine health, orbital movement, sensor monitoring, and mission analytics.

## ✨ Key Features
### 🌍 Mission Tracking & Visualization
- Real-time mission location tracking with interactive maps
- Orbital position visualization and mission movement
- Mission-wise comparative analytics

### 📊 Telemetry & Performance Monitoring
- Engine thrust performance analysis
- Velocity vs. acceleration monitoring
- Altitude tracking
- Engine temperature monitoring
- Fuel remaining indicators
- Orbital phase overview

### 🛰️ Sensor Analytics
- Mission-specific sensor display
- Sensor health and operational status monitoring
- Real-time telemetry-style gauges and KPI indicators

### 📈 Interactive Dashboard Components
- Dynamic charts and graphs
- KPI cards and gauge visuals
- Geospatial mapping with Bing Maps
- Mission filters and slicers
- Comparative mission analysis
